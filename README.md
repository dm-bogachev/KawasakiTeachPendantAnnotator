# Robot Panel Annotator

Небольшое настольное приложение на Python + PySide6 для разметки скриншотов пульта робота.

## Возможности
- Открытие изображения с диска или вставка изображения из буфера обмена.
- Выбор ячеек сетки 7×4 кликом по изображению.
- Выделение дополнительных областей (например, верхних индикаторов и окон) прямоугольником мышью.
- Поля элемента: номер, английское название, описание на русском. Все поля необязательны.
- Экспорт в Word: размеченная картинка, ниже таблица элементов; изображение ячейки в таблице можно отключить.
- Сохранение/загрузка проекта JSON. Если картинка вставлена из буфера, она встраивается в JSON; если открыта с диска, проект хранит путь к ней.

## Установка

Python 3.10+ рекомендуется.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

python -m pip install -r requirements.txt
python main.py
```

## Зависимости
- PySide6 — интерфейс
- python-docx — экспорт в DOCX

## Примечания
- Координаты сетки по умолчанию настроены под изображение 642×512 из исходного примера. Если геометрия сетки на других изображениях отличается, отредактируйте константу `GRID` в `main.py`.
- Номера в Word сортируются численно, если номер состоит только из цифр; остальные идут после них.
- Для сохранения проекта с изображением, загруженным с диска, файл изображения должен оставаться по исходному пути. Для автономного проекта можно вставить изображение через буфер обмена перед сохранением.
